# CampusFlow

## Project Goal
To develop a Python command-line help desk application that enables Learn2Earn campus staff to create, prioritize,
assign, track, and report technical support tickets, with JSON data persistence and automated testing, while 
demonstrating effective GitHub collaboration and responsible AI-assisted learning.
